# THE SINGING GUITAR — VERSION 2
## A Complete Performance Course in Blues, Jazz & Neo-Soul Lead Guitar
### 30 Weeks | From First Note to 10-Song Solo Recital

---

# THE PROMISE

By the end of Week 30, you will be able to pick up your guitar and play **10 complete songs** for yourself or for others — solo pieces that sound like music, not exercises.

This is not a theory course. This is a **repertoire course**. Every week, you learn a piece of music. The theory emerges naturally, only when it helps you sound better.

**What you need:**
- Any electric guitar
- A tuner (phone app)
- A pick (0.73mm medium)
- 20–30 minutes per day
- A metronome (phone app)
- This document

**How to read tabs:**
```
e|-----5-----|  <- 1st string (thinnest)
B|-----5-----|  <- 2nd string
G|-----5-----|  <- 3rd string
D|-----5-----|  <- 4th string
A|-----5-----|  <- 5th string
E|-----5-----|  <- 6th string (thickest)
```
Numbers = fret. `0` = open string. `b` = bend. `~` = vibrato. `h` = hammer-on. `p` = pull-off. `/` = slide up. `\` = slide down.

**Fingers:** 1 = index, 2 = middle, 3 = ring, 4 = pinky.

**SONG 1: "Seven Nation Army" (The White Stripes)**

```
A|-----0-----0-----2-----0-----5-----3-----0-----|
```

**How to play:**
- Pick the A string with downstrokes only.
- Let each note ring until the next one starts.
- Play along with the original recording. It is slow and heavy.

**SONG 2: "Smoke on the Water" (Deep Purple)**

```
G|-----0-----3-----5-----0-----3-----6--5-----|
D|-----0-----3-----5-----0-----3-----6--5-----|
```

**How to play:**
- Place one finger across both the G and D strings at the same fret (this is called "barring").
- Pick both strings together with one stroke.
- Move the shape to 3rd fret, then 5th, then 6th, back to 5th.

**Day 1–2:** Play only the D string until the pattern is in your fingers.
**Day 3–4:** Add the G string. Both notes must ring equally.
**Day 5–7:** Play along with the recording.

# PHASE 1: THE BLUES REPERTOIRE
## Weeks 3–10 | 6 Complete Blues Songs You Can Perform Solo

### WEEK 3: "Mannish Boy" — Your First Blues Groove

**Time:** 25 min/day

**Why this song:** The riff repeats for the entire song. Learn it once, play it forever. It is one of the most iconic blues guitar parts ever recorded. cite🛠web_search:6#0:~:text=Mannish Boy...most iconic blues guitar riffs of all time

**The Riff (simplified for one guitar):**

```
E|-------------------------------------|
A|-------------------------------------|
D|-------------------------------------|
G|-------------------------------------|
B|-----3-----3--3--3-----3--3--3-----3--|
e|-----0-----0--0--0-----0--0--0-----0--|
```

**How to play:**
- Pick the e and B strings together.
- The rhythm is: DU-DU-DU (Down-Up-Down-Up-Down-Up) in a triplet feel.
- Mutter "da-da-da, da-da-da" as you play. That is the blues groove.

**Day 1–2:** Play the riff slowly. No groove yet — just clean notes.
**Day 3–4:** Add the triplet feel. Tap your foot.
**Day 5–6:** Play for 2 minutes without stopping. This builds stamina.
**Day 7:** Record yourself playing the riff for 1 minute straight.

---

### WEEK 4: "The Thrill Is Gone" — Your First Real Solo

**Time:** 25 min/day

**Why this song:** B.B. King's slow blues masterpiece. The solo is melodic, slow, and uses only the minor pentatonic scale. It teaches you that one well-placed note is worth ten fast ones.

**The A Minor Pentatonic Scale (Box 1):**

```
e|-----5-----8-----|
B|-----5-----8-----|
G|-----5-----7-----|
D|-----5-----7-----|
A|-----5-----7-----|
E|-----5-----8-----|
```

**Fingering:** 5th fret = finger 1. 7th fret = finger 3. 8th fret = finger 4.

**The Intro (4 notes that changed guitar history):**

```
e|-----------------|
B|-----8b10--------|  <- Bend up a whole step, hold, vibrato
G|-----------------|
```

**How to bend:**
1. Place finger 3 on the 8th fret B string.
2. Place fingers 1 and 2 on the same string behind finger 3 (they help push).
3. Pick the note. Push the string UP toward the ceiling until the pitch rises to match the 10th fret.
4. Hold the bent note for 2 seconds.
5. Add vibrato: rock your hand back and forth slightly.

**The full intro phrase:**

```
e|-----------------|
B|-----8b10--------|
G|-----------------|
D|-----------------|
A|-----------------|
E|-----------------|

(Rest 2 beats)

e|-----------------|
B|-----8-----5-----|
G|-----------------|
D|-----------------|

(Rest 2 beats)

e|-----------------|
B|-----------------|
G|-----7-----5-----|
D|-----------------|
```

**Day 1:** Learn the scale shape. Play it up and down 20 times.
**Day 2:** Practice the bend. 10 minutes. Your fingertip will hurt. This is normal.
**Day 3:** Learn the first 4 notes of the intro.
**Day 4:** Learn the full 8-bar intro.
**Day 5–6:** Play along with the original recording.
**Day 7:** Record the intro over a backing track (YouTube: "A minor slow blues backing track 70 bpm").

---

### WEEK 5: "Mary Had a Little Lamb" (Buddy Guy Version)

**Time:** 25 min/day

**Why this song:** Buddy Guy's version is a blues guitar instrumental built on a simple, singable melody. It teaches you to play a melody like a vocalist sings it — with bends, vibrato, and space. cite🛠web_search:6#0:~:text=Mary Had A Little Lamb...Buddy Guy's is a little easier to learn at first

**The Melody (simplified in A minor pentatonic):**

```
e|-------------------------------------|
B|-----5--8b10--8--5-----------------|
G|---------------------7--5-----------|
D|-------------------------------------|
```

**Phrase 2:**
```
e|-------------------------------------|
B|-----5--8--5------------------------|
G|--------------7--5--7--5-------------|
D|-------------------------------------|
```

**How to play:**
- Each phrase is a "sentence." Play it, then breathe.
- The bend on 8b10 must reach the correct pitch. Check by playing the 10th fret normally — the bent note should sound identical.
- Leave space between phrases. Silence is part of the music.

**Day 1–2:** Learn Phrase 1. Play it 30 times.
**Day 3–4:** Learn Phrase 2.
**Day 5–6:** Chain them together. Add your own variations.
**Day 7:** Record the full melody.

---

### WEEK 6: "Boom Boom" (John Lee Hooker)

**Time:** 25 min/day

**Why this song:** Another iconic riff that repeats throughout. John Lee Hooker played loose and free — you can too. It teaches groove over precision. cite🛠web_search:6#0:~:text=Boom Boom...riff in 'Boom Boom' is instantly recognisable and very catchy

**The Riff:**

```
E|-------------------------------------|
A|-------------------------------------|
D|-------------------------------------|
G|-----2--2--2--2--4--4--4--4----------|
B|-----2--2--2--2--4--4--4--4----------|
e|-----0--0--0--0--0--0--0--0----------|
```

**How to play:**
- Pick all three strings together (e, B, G).
- The rhythm is a shuffle: "da-da, da-da, da-da, da-da."
- Move the shape from 2nd fret to 4th fret and back.

**Day 1–2:** Learn the riff at 60% speed.
**Day 3–4:** Add the shuffle feel.
**Day 5–6:** Play along with the recording.
**Day 7:** Record yourself.

### WEEK 7: "Born Under a Bad Sign" (Albert King)

**Time:** 25 min/day

**Why this song:** Albert King's bends are enormous and expressive. The riff is iconic and the solo is entirely in the minor pentatonic box you already know. cite🛠web_search:6#0:~:text=Born Under A Bad Sign...Albert King is widely recognised as one of the most intense and expressive lead blues guitar players

**The Riff:**

```
E|-------------------------------------|
A|-------------------------------------|
D|-----5--5--5--5--7--7--7--7----------|
G|-----5--5--5--5--7--7--7--7----------|
B|-----5--5--5--5--7--7--7--7----------|
e|-------------------------------------|
```

**How to play:**
- Barre your index finger across the D, G, and B strings at the 5th fret.
- Pick all three strings together.
- Move the shape to 7th fret. The jump should be clean and immediate.

**The Solo Lick (first phrase):**
```
e|-------------------------------------|
B|-----8b10--8--5----------------------|
G|-----------------7--5----------------|
D|-------------------------------------|
```

**Day 1–2:** Learn the riff.
**Day 3–4:** Learn the solo lick.
**Day 5–6:** Play riff + solo lick over a backing track.
**Day 7:** Record a 1-minute performance: 30 seconds riff, 30 seconds soloing.

### WEEK 8: "Sweet Little Angel" (B.B. King) — The B.B. Box

**Time:** 25 min/day

**Why this song:** B.B. King spent his career in a tiny 4-fret area (frets 10–13). This week, you enter that space and learn why he never needed to move.

**The B.B. Box:**

```
e|-----10-----13-----|
B|-----11-----13-----|
G|-----10-----12-----|
```

**Fingering:** 10 = finger 1, 11 = finger 2, 12 = finger 3, 13 = finger 4.

**The Intro:**
```
e|-----13b15-----13-----10-----|
B|-----------------------------|
G|-----------------------------|
```

**How to play:**
- Bend the 13th fret e string up to the 15th fret pitch.
- Add vibrato. This note should sound like a human voice crying.
- The release to 13, then 10, creates a "falling" emotional effect.

**Day 1–2:** Learn the B.B. Box shape.
**Day 3–4:** Practice the 13b15 bend. It is harder than the 8b10 — the string is thinner and requires more control.
**Day 5–6:** Learn the full intro.
**Day 7:** Record it.

### WEEK 9: "Red House" (Jimi Hendrix) — Call and Response

**Why this song:** Hendrix's slow blues teaches the most important soloing skill: having a conversation with yourself. Play a phrase, answer it.

**Call:**
```

B|-----8b10--------|
G|-----------------|
```

**Response:**
```
e|-----------------|
B|-----8-----5-----|
G|-----------------|
```

**Call:**
```
e|-----------------|
B|-----------------|
G|-----7b9---------|
```

**Response:**
```
e|-----------------|
B|-----------------|
G|-----7-----5-----|
```

**Day 1–2:** Learn the calls.
**Day 3–4:** Learn the responses.
**Day 5–6:** Chain them. Leave 2 beats of silence between each call and response.
**Day 7:** Record a 1-minute solo using only call-and-response.

# PHASE 2: JAZZ STANDARDS
## Weeks 11–18 | 5 Complete Melodies + Simplified Solos

**Important:** Jazz is not harder than blues. It is different. The notes are often closer together, and the timing is more precise. But the melodies are beautiful and slow. You can do this.

### WEEK 11: "Autumn Leaves" — The Melody

**Time:** 25 min/day

**Why this song:** The most famous jazz standard for guitarists. The melody is lyrical, slow, and teaches you how to resolve tension. cite🛠web_search:6#2:~:text=Autumn Leaves is a must-know jazz standard

**Key:** E minor / G major. We will play it in a simplified guitar-friendly key.

**The Melody (simplified, single-string version):**

```
e|-----0-----3-----0-----------|
B|-----------0-----------3-----|
G|-----------------0-----------|
```

**Phrase 2:**
```
e|-----------------|
B|-----3-----0-----|
G|-----------------|
```

**Full melody (8 bars):**
```
e|-----0--3--0-----------0--3--0-----------|
B|--0-----------3-----0-----------0--3-----|
G|--------------0-----------------0--------|
```

**How to play:**
- Play it slowly. Sing the melody as you play.
- Each note should connect to the next like a singer's breath.
- Use a clean tone. Neck pickup. Roll your tone knob down slightly.

**Day 1–3:** Learn the melody note for note. Play it 20 times.
**Day 4–5:** Play with a metronome at 60 BPM.
**Day 6–7:** Play along with a recording of "Autumn Leaves." Match the singer's phrasing.

### WEEK 12: "Blue Bossa" — Your First Jazz Solo

**Time:** 30 min/day

**Why this song:** A 16-bar minor blues. The melody is short and beautiful. The solo is mostly minor pentatonic — the same scale you learned in Phase 1, just moved to C minor. cite🛠web_search:6#2:~:text=Blue Bossa...short 16-bar form and has really basic harmony

**C Minor Pentatonic (move your A minor box up 3 frets):**

```
e|-----8-----11-----|
B|-----8-----11-----|
G|-----8-----10-----|
D|-----8-----10-----|
A|-----8-----10-----|
E|-----8-----11-----|
```

**The Melody:**
```
e|--------------------------------|
B|-----6-----8--6-----6-----------|
G|--5-----------5--------7--5-----|
```

**The Solo Approach:**
1. Play the melody.
2. Improvise using ONLY the C minor pentatonic box.
3. When you want to sound "jazzy," add the note on the 10th fret G string (the major 6th).

**Day 1–3:** Learn the melody.
**Day 4–5:** Improvise over a "Blue Bossa" backing track. Stay in the box.
**Day 6–7:** Record melody + one chorus of solo.

### WEEK 13: "Take the A Train" — Swing Feel

**Time:** 25 min/day

**Why this song:** The A-part is a common progression you will find in many other songs. It teaches swing feel — the "long-short" rhythm that makes jazz sound like jazz. cite🛠web_search:6#3:~:text=Take The A-train is again an AABA form...common progression that you will find in a lot of other songs

**The Melody (simplified, first 4 bars):**

```
e|-----5--7--8--7--5---------------|
B|---------------------5--7--5-----|
G|---------------------------------|
```

**The Swing Feel:**
- Jazz is not played straight. Each beat is divided into "long-short."
- Say "da-DUM, da-DUM" as you play. The first note is longer, the second is shorter.
- This is called "swing eighths."

**Day 1–2:** Learn the melody straight (no swing yet).
**Day 3–4:** Add the swing feel.
**Day 5–6:** Play along with a recording.
**Day 7:** Record yourself.

### WEEK 16: Jazz Vocabulary — The ii-V-I Lick

**Time:** 25 min/day

**Why this week:** You need one jazz "lick" — a short phrase that works over the most common chord progression in jazz.

**The ii-V-I in C major:**
- Dm7 → G7 → Cmaj7

**The Lick:**
```
e|-------------------------------------|
B|-----6--5----------------------------|
G|-----------7--5--4--5----------------|
D|-------------------------------------|
```

**How to play:**
- Play it slowly. This lick outlines the Dm7 chord, resolves to the G7, and lands on the C.
- Practice it in all 12 keys by moving the shape up and down the neck.

**Day 1–3:** Learn the lick in C.
**Day 4–5:** Move it to F, G, and Bb.
**Day 6–7:** Insert it into your "Autumn Leaves" solo.

### WEEK 17: "Chitlins Con Carne" — Blues-Jazz Graduation

**Time:** 30 min/day

**Why this song:** Kenny Burrell's medium blues in C. The solo is almost entirely C minor pentatonic with chromatic approach notes. If you can play "The Thrill Is Gone," you can play this. cite🛠web_search:6#4:~:text=Chitlins Con Carne - Burrell...anything Charlie Christian, anything Grant Green

**The Approach:**
1. Play C minor pentatonic over the Cm7 chord.
2. When the chord changes to F7, slide your lick up 5 frets (to F minor pentatonic position).
3. When it changes to G7, slide up 2 more frets.
4. Return to C minor pentatonic.

This is called "chasing the changes."

**Day 1–3:** Practice moving the pentatonic box to follow chords.
**Day 4–5:** Improvise over a C minor blues track.
**Day 6–7:** Record a solo.

# PHASE 3: NEO-SOUL FEEL
## Weeks 19–24 | Creating Your Own Instrumental Pieces

**The Honest Truth:** Neo-soul is a vocal genre. There are almost no famous "neo-soul guitar solos" because the guitar rarely takes the lead role. Instead, this phase teaches you the **language** of neo-soul guitar — double stops, syncopation, and laid-back feel — and helps you compose 3 original instrumental pieces using that language.

### WEEK 19: Double Stops — The Neo-Soul Signature

**Time:** 25 min/day

**The Technique:** Playing two notes at once — usually a major 3rd or 6th apart. This creates the "smooth, expensive" neo-soul sound.

**Shape 1 — Major 3rd (C + E):**
```
G|-----5-----|
B|-----5-----|
```

**Shape 2 — Major 3rd (D + F#):**
```
G|-----7-----|
B|-----7-----|
```

**The Exercise:**
1. Play Shape 1. Let it ring for 2 beats.
2. Slide to Shape 2. Let it ring.
3. Slide back.

```
G|-----5--/7--/5-----|
B|-----5--/7--/5-----|
```

**Day 1–3:** Get both notes ringing equally. No buzzing.
**Day 4–5:** Add rhythm. Play on beat 1, rest on beat 2, slide on beat 3, rest on beat 4.
**Day 6–7:** Record a 1-minute groove using only these two shapes.

---

### WEEK 20: The Pocket — Playing Behind the Beat

**Time:** 25 min/day

**The Concept:** Neo-soul guitar does not play ON the beat. It plays slightly AFTER it. This creates a relaxed, "laid-back" feel.

**Exercise:**
1. Set a metronome to 70 BPM.
2. Play a single note on beat 1. But wait a tiny moment after the click.
3. It should feel like the note is "settling" into the groove, not "attacking" it.

**The Lick:**
```
G|-----5-----5h7-----5-----|
B|--------------------------|
```

**Day 1–3:** Practice the drag with one note.
**Day 4–5:** Add the hammer-on lick. Play it behind the beat.
**Day 6–7:** Record.

---

### WEEK 21: Hammer-Ons and Pull-Offs — Legato Feel

**Time:** 25 min/day

**The Technique:** Not picking every note. Using hammer-ons and pull-offs to create a smooth, vocal-like line.

**Exercise:**
```
G|-----5h7p5-----5h7-----|
B|-----------------------|
```

**How to play:**
- Pick the 5th fret.
- Hammer finger 3 onto the 7th fret (no second pick).
- Pull finger 3 off (pluck the string with your fretting finger) to return to 5.
- Hammer back to 7.

**Day 1–3:** Practice until smooth and even.
**Day 4–5:** Add a bend: `5h7p5 7b9` (bend the 7th, add vibrato).
**Day 6–7:** Chain into a 4-bar phrase.

---

# APPENDIX A: THE 5-MINUTE WARM-UP

Do this before every practice session:

1. **Finger stretches (1 min):** Spread fingers wide, make a fist. Repeat 10 times.
2. **Single-string picking (1 min):** Pick open A string 50 times. Focus on consistency.
3. **Pentatonic review (2 min):** Play A minor pentatonic up and down. Say fret numbers.
4. **Bend check (1 min):** Bend 8th fret B string to pitch. Check with 10th fret. Do 5 times.

# APPENDIX B: TROUBLESHOOTING

| Problem | Cause | Fix |
|---------|-------|-----|
| String buzzes | Finger too far from fret | Move finger closer to metal bar |
| Note sounds dead | Finger touching adjacent string | Curl finger more, use fingertip |
| Bend won't reach pitch | Not pushing hard enough | Use fingers 1+2 to support finger 3 |
| Hand cramps | Gripping too tight | Shake hand out, practice lighter |
| Pick keeps slipping | Holding it wrong | Hold like a coin between thumb and index side |
| Can't keep time | No internal pulse | Tap your foot. Always. |
| Solo sounds like a scale | Playing too many notes | Play half as many notes. Leave space. |
| Bored | Practicing too long | Stop at 20 minutes. Come back tomorrow. |
