# The Singing Guitar

A free, mobile-friendly 30-week electric guitar performance course covering blues, jazz and neo-soul. Learners move from their first riff to a 15-minute solo recital without an account or subscription.

## What is included

- 30 structured weekly lessons from the complete course
- 14-song and original-piece repertoire
- Course tabs and notation in a focused tab view
- Curated free YouTube companion lessons for every week
- Seven-day practice plans and related-lesson references
- Interactive metronome and practice timer
- Backing-track library
- Device-local progress, completion tracking and lesson notes
- Responsive layout for phone, tablet and desktop

## Run locally

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

## Publish free with GitHub Pages

This repository includes an automatic Pages workflow.

1. Create a public GitHub repository and upload the project files.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **GitHub Actions**.
4. Push to the `main` branch. The included workflow builds and publishes the site.

The configuration automatically supports both project URLs (`username.github.io/repository`) and account URLs (`username.github.io`).

## Content note

The tablature in the app is the simplified educational material supplied with *The Singing Guitar — Version 2*. Linked videos remain on their creators’ channels. Song names and artist names are used for identification and instruction.
